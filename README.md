# homebrew-leo

A Homebrew tap for [leo](https://github.com/StealthFactory/leo), a tiny,
extensible command-line sidekick with a JSON object store.

## Install

```sh
brew tap stealthfactory/leo
brew trust stealthfactory/leo
brew install --cask leo
```

Or in one line without tapping first:

```sh
brew install --cask stealthfactory/leo/leo
```

## Upgrade

```sh
brew update
brew upgrade --cask leo
```

## Uninstall

```sh
brew uninstall --cask leo
brew untap stealthfactory/leo
```

## What's here

`Casks/leo.rb` is generated by Leo's release workflow and installs the signed,
notarized binary matching the Mac's architecture. The legacy `Formula/leo.rb`
remains in this repository until the first cask-backed release passes its
installation smoke test.

Existing formula users should migrate once:

```sh
brew uninstall leo
brew install --cask leo
```

See the [main repo](https://github.com/StealthFactory/leo) for what Leo does and
how to use it.
